# Satya Academy — Interactive Exercises

A static prototype for interactive mathematics practice.

## Current demo
- Pre-Algebra: Adding Integers
- Five questions with numerical answer checking
- Per-question hints and worked solutions
- Previous/next navigation
- Progress indicator and score summary
- Responsive layout and keyboard Enter-to-check support

## Run locally
Open `index.html` in a modern browser. No build step or dependencies are required.

## Deploy
The site is published with GitHub Pages from the `main` branch.

## Important limitations
- This is a front-end demonstration. Answers are present in the public JavaScript source.
- Scores are held only in browser memory and are not saved or sent to a teacher.
- Do not place private question banks, answer keys, student data, or credentials in this public repository.
- Do not use this prototype for secure or graded assessments.
